src/certify/smoothing.py (MAIN ALGORITHM)
  Purpose: Core certification pipeline
  Class: RandomizedSmoothingAttributor
  Key methods:
    - certify(image, k_percent, ...) → results dict
      Implements equations 5-7
      Input: image, hyperparameters
      Output: certified_map {-1,0,1}, p_1, p_0, certified_radius
    - _sparsify_topk(heatmap, k_percent)
      Implements equation 4
      Input: [H,W] heatmap
      Output: [H,W] binary mask
  Key parameters:
    σ (sigma): noise std deviation (paper: 0.15)
    τ (tau): certification threshold (paper: 0.75)
    n (num_samples): smoothing samples (paper: 100)
    K (k_percent): sparsification level (paper: 50,30,10)

src/xai/attribution_unified.py (ATTRIBUTION INTERFACE)
  Purpose: Unified interface for attribution methods
  Classes:
    - AttributionMethod(ABC)
      Base class with abstract method: attribute(image, target_class)
    - IntegratedGradientsUnified
      Eq. (2): Integrated Gradients method
      Returns: [H,W] normalized heatmap
    - GradCAMUnified
      Eq. (2): Grad-CAM method
      Returns: [H,W] normalized heatmap
    - RISEUnified
      Eq. (2): RISE method
      Returns: [H,W] normalized heatmap
    - OcclusionUnified
      Eq. (2): Occlusion method
      Returns: [H,W] normalized heatmap
  Interface:
    heatmap = attribution_method.attribute(image, target_class)
    Returns: [H,W] in range [0, 1]

src/models/factory.py (MODEL FACTORY)
  Purpose: Create models (Eq. 1)
  Function: get_model(model_name, num_classes, pretrained)
  Supported models:
    - resnet18, resnet50
    - densenet121
    - efficientnet_b0, efficientnet_b1
  Usage:
    model, config = get_model('resnet18', num_classes=2)
    output = model(image)  # [B, num_classes]

src/certify/evaluate.py
  Purpose: Evaluation metrics
  Function: evaluate_certified(results)
  Computes: metrics from certification results

=============================================================================
PARAMETER SETTINGS (QUICK REFERENCE)
=============================================================================

Paper defaults:
  σ (sigma) = 0.15          # Noise std
  τ (tau) = 0.75            # Threshold
  n (num_samples) = 100     # Samples
  K (k_percent) = [50, 30, 10]  # Sparsification

Recommended ranges:
  σ: [0.10, 0.15, 0.20]     # Higher = more robust
  τ: [0.60, 0.75, 0.90]     # Higher = stricter
  n: [100, 200]             # Higher = more reliable
  K: [10, 30, 50]           # Higher = easier to certify
