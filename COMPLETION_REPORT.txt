=============================================================================
HOW TO USE THE IMPLEMENTATION
=============================================================================

Minimal Example:
  
  import torch
  from src.models.factory import get_model
  from src.xai.attribution_unified import GradCAMUnified
  from src.certify.smoothing import RandomizedSmoothingAttributor
  
  # Load model (Eq. 1)
  model, _ = get_model('resnet18', num_classes=2)
  
  # Create attribution method (Eq. 2-3)
  attr = GradCAMUnified(model)
  
  # Create smoother (Eq. 4-7)
  smoother = RandomizedSmoothingAttributor(
      model, 
      lambda img, cls: attr.attribute(img, target_class=cls)
  )
  
  # Certify image
  image = torch.randn(1, 3, 224, 224)
  results = smoother.certify(
      image=image,
      k_percent=30,
      target_class=1,
      sigma=0.15,
      tau=0.75,
      num_samples=100
  )
  
  # Get results
  cert_map = results['certified_map']  # {-1, 0, 1}
  radius = results['certified_radius']  # R = σ·Φ^(-1)(τ)

Output Interpretation:
  - cert_map == 1: Certified as important (green)
  - cert_map == 0: Certified as unimportant (red)
  - cert_map == -1: Uncertain, abstain (gray)
  - radius: Robustness guarantee in L2 norm

=============================================================================
HYPERPARAMETERS (Paper Defaults)
=============================================================================

σ (sigma) = 0.15
  Noise standard deviation
  Larger → more robust but fewer certified pixels

τ (tau) = 0.75
  Certification threshold
  Larger → stricter certification but larger radius

K (k_percent) = [50, 30, 10]
  Sparsification levels
  Paper tests all three values

n (num_samples) = 100
  Number of smoothing samples
  Larger → better estimates but slower

α (alpha) = 0.001
  Statistical significance level
