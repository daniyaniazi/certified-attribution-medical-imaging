WHAT HAS BEEN IMPLEMENTED
==========================

A production-ready Python project for certified pixel attribution on medical images.

The implementation includes:

1. COMPLETE PIPELINE
   - Train models on medical imaging datasets
   - Generate explanations using multiple attribution methods
   - Certify robustness of explanations via randomized smoothing
   - Evaluate faithfulness and localization

2. MULTIPLE DATASETS
   - CheXpert (chest X-ray) - pneumonia classification
   - ISIC (skin lesion) - melanoma classification
   - Extensible for APTOS, ImageNet, etc.

3. MULTIPLE MODELS
   - ResNet-18, ResNet-50
   - DenseNet-121
   - EfficientNet-B0, EfficientNet-B1
   - All with pretrained ImageNet weights

4. ATTRIBUTION METHODS
   - Integrated Gradients (IG)
   - Grad-CAM
   - RISE (Randomized Input Sampling)
   - Occlusion (perturbation-based)

5. CERTIFICATION PIPELINE
   - Sparsification (top-K pixels)
   - Randomized smoothing with Gaussian noise
   - Majority voting per pixel
   - Threshold-based certification
   - Abstention for uncertain pixels

6. COMPREHENSIVE EVALUATION
   - Faithfulness (deletion AUC)
   - Localization accuracy (IoU)
   - Sensitivity & Specificity
   - Certification statistics

7. FULL DOCUMENTATION
   - README.md (comprehensive overview)
   - QUICKSTART.md (step-by-step guide)
   - Docstrings for all functions/classes
   - Working examples (example.py)
   - Setup verification (verify_setup.py)

QUICK START
===========

1. Install Dependencies:
   pip install -r requirements.txt

2. Verify Setup:
   python verify_setup.py

3. Run Examples:
   python example.py

4. Download Data:
   - CheXpert: https://stanfordmlgroup.github.io/competitions/chexpert/
   - ISIC: https://www.isic-archive.com/

5. Train Model:
   python src/experiments/run_train.py --dataset chexpert --model resnet18 --epochs 50

6. Generate Attributions:
   python src/experiments/run_attribution.py --checkpoint outputs/checkpoints/chexpert/resnet18/best_model.pt --method integrated_gradients

7. Certify Attributions:
   python src/experiments/run_certify.py --checkpoint outputs/checkpoints/chexpert/resnet18/best_model.pt --sigma 0.15 --tau 0.75 --num-samples 100

8. Evaluate:
   python src/experiments/run_eval.py --checkpoint outputs/checkpoints/chexpert/resnet18/best_model.pt

KEY HYPERPARAMETERS
====================

Certification (randomized smoothing):
- sigma: 0.15           # Gaussian noise standard deviation
- tau: 0.75             # Certification threshold
- num_samples: 100      # Number of smoothing iterations
- k_percents: [50, 30, 10]  # Sparsification percentiles

Training:
- epochs: 100
- learning_rate: 1e-3
- batch_size: 32
- weight_decay: 1e-5
- metric_to_track: 'val_auc'

EXAMPLE CODE
============

# Train a model
from src.models.factory import get_model
from src.datasets.chexpert import CheXpertDataset
from src.train.train_one import Trainer
from torch.utils.data import DataLoader

model, config = get_model('resnet18', num_classes=2)
dataset = CheXpertDataset(split='train')
loader = DataLoader(dataset, batch_size=32)
trainer = Trainer(model, loader, val_loader, device='cuda')
trainer.fit(epochs=50)

# Generate and certify attributions
from src.xai.attribution import IntegratedGradients
from src.certify.smoothing import RandomizedSmoothingAttributor
from src.certify.sparsify import sparsify_topk

ig = IntegratedGradients(model)
smoother = RandomizedSmoothingAttributor(model, ig.attribute)

image = torch.randn(1, 3, 224, 224)
attr = ig.attribute(image, target_class=1)
sparse = sparsify_topk(attr, k_percent=30)
certified, votes, pct = smoother.certify(
    image, sparse, target_class=1,
    sigma=0.15, tau=0.75, num_samples=100
)
print(f"Certified: {pct:.1f}%")

HOW TO EXTEND
=============

Add a New Dataset:

2. Implement _load_data() and _load_image()
3. Add to dataset loaders

Add a New Model:
1. Add case to get_model() in factory.py
2. Update model configs
3. Use in experiments

Add a New Attribution Method:
1. Create class with attribute() method
2. Implement in src/xai/attribution.py
3. Add to run_attribution.py

Add Custom Evaluation:
1. Extend CertificationEvaluator
2. Add metric computation
3. Use in run_eval.py
