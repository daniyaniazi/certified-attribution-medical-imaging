EQUATION (1): CLASSIFIER

Mathematical form:
  f: X → Y
  f(x) = logits ∈ ℝ^{num_classes}
  y_pred = argmax f(x)

Interpretation:
  Neural network that maps images to class predictions
  Core component for attribution (we need to explain f's decisions)

Implementation location:
  File: src/models/factory.py
  Function: get_model(model_name, num_classes, pretrained)

Code example:
  from src.models.factory import get_model

  image = torch.randn(1, 3, 224, 224)  # Batch of 1 image
  logits = model(image)  # [1, 2] output
  pred = logits.argmax(dim=1).item()  # Class 0 or 1

Supported models:
  - ResNet: resnet18, resnet50
  - DenseNet: densenet121
  - EfficientNet: efficientnet_b0, efficientnet_b1

=============================================================================
EQUATION (2-3): ATTRIBUTION METHOD
=============================================================================

Mathematical form:
  h(f, x, y) ∈ ℝ^{H×W}
  
  Where:
    f = classifier
    x = input image
    y = target class
    h(x)[i,j] = importance score of pixel (i,j) for predicting class y
  
  Normalization: h(x) ∈ [0, 1]

Interpretation:
  Attribution map shows which pixels are important for the model's
  prediction of class y. Higher values = more important.
  
  Used as input to certification pipeline (Eq. 5)

Implementation location:
  File: src/xai/attribution_unified.py
  Base class: AttributionMethod (abstract)
  Concrete implementations:
    - IntegratedGradientsUnified
    - GradCAMUnified
    - RISEUnified
    - OcclusionUnified

Code example:
  from src.xai.attribution_unified import GradCAMUnified
  import torch
  
  # Create classifier (Eq. 1)
  from src.models.factory import get_model
  model, _ = get_model('resnet18', num_classes=2)
  
  # Create attribution method (implements Eq. 2-3)
  attr = GradCAMUnified(model)
  
  # Compute attribution
  image = torch.randn(1, 3, 224, 224)
  target_class = 1
  heatmap = attr.attribute(image, target_class=target_class)
  
  # Result
  print(heatmap.shape)  # (224, 224) - per-pixel importance
  print(heatmap.min(), heatmap.max())  # 0.0, 1.0 - normalized
  
  # Green pixels (high values) = important
  # Dark pixels (low values) = not important

Method specifics:

  IntegratedGradientsUnified:
    - Baseline integration approach
    - Reference: Sundararajan et al. (2017)
    - Good for: general interpretability
  
  GradCAMUnified:
    - Gradient-weighted class activation mapping
    - Reference: Selvaraju et al. (2016)
    - Good for: CNN layer visualization, efficiency
    - Used in examples for speed
  
  RISEUnified:
    - Randomized input sampling
    - Reference: Petsiuk et al. (2018)
    - Good for: model-agnostic approach
  
  OcclusionUnified:
    - Perturbation-based sliding window
    - Reference: Zeiler & Fergus (2013)
    - Good for: simple baseline

=============================================================================
EQUATION (4): SPARSIFICATION
=============================================================================

Mathematical form:
  h_K(x) = Top-K%(h(x))
  
  Where:
    h(x) ∈ ℝ^{H×W} = continuous heatmap (Eq. 2-3)
    K = percentage (e.g., 30 means keep top 30%)
    h_K(x) ∈ {0, 1}^{H×W} = binary mask
  
  Algorithm:
    threshold = percentile(h(x), 100 - K)
    h_K(x)[i,j] = 1 if h(x)[i,j] >= threshold
                = 0 otherwise

Interpretation:
  Converts continuous importance scores to binary segmentation.
  Top-K% pixels marked as important (1), rest as unimportant (0).
  
  Why needed? To enable majority voting (can't vote on real values)

Implementation location:
  File: src/certify/smoothing.py
  Class: RandomizedSmoothingAttributor
  Method: _sparsify_topk(heatmap, k_percent)

Code example:
  import numpy as np
  from src.certify.smoothing import RandomizedSmoothingAttributor
  
  # Create dummy heatmap (Eq. 2-3 output)
  heatmap = np.random.rand(224, 224)  # [0, 1]
  
  # Sparsify to binary mask (implements Eq. 4)
  k_percent = 30  # Keep top 30%
  threshold = np.percentile(heatmap.flatten(), 100 - k_percent)
  mask = (heatmap >= threshold).astype(np.float32)  # {0, 1}
  
  # Verify
  print(np.mean(mask))  # Should be ~0.30 (30% are 1)
  print(mask.dtype)  # float32
  print(np.unique(mask))  # [0., 1.]

Variations with different K:
  K = 50%: Keep top half (easier to certify, smaller R)
  K = 30%: Keep top 30% (moderate trade-off)
  K = 10%: Keep top 10% (harder to certify, larger R)

=============================================================================
EQUATION (5): RANDOMIZED SMOOTHING & CERTIFICATION
=============================================================================

Mathematical form (Algorithm):
  
  Input: x (image), h (attribution), f (classifier), y (class),
         σ (noise std), K (sparsification %), τ (threshold), n (samples)
  
  Procedure:
  
    1. For t = 1 to n:
         ε_t ~ N(0, σ²I)                    [Sample Gaussian noise]
         x_t = clip(x + ε_t, [0, 1])        [Noisy image]
         heat_t = h(f, x_t, y)              [Eq. 2-3: attribution]
         mask_t = h_K(x_t)                  [Eq. 4: sparsify]
         count_1 += mask_t                  [Vote for class 1]
         count_0 += (1 - mask_t)            [Vote for class 0]
    
    2. Compute per-pixel probabilities:
         p_1[i] = count_1[i] / n   [Probability important]
         p_0[i] = count_0[i] / n   [Probability unimportant]
    
    3. Certify with threshold τ:
         For each pixel [i, j]:
           If p_1[i,j] >= τ:
             cert[i,j] = 1      [Certified important]
           Else if p_0[i,j] >= τ:
             cert[i,j] = 0      [Certified unimportant]
           Else:
             cert[i,j] = ⊘ = -1 [Abstain (uncertain)]
  
  Output: cert ∈ {-1, 0, 1}^{H×W}, p_1, p_0 ∈ [0,1]^{H×W}

Interpretation:
  A pixel is certified important if, across n noisy samples, it remains
  in the top K% at least τ×100% of the time.
  
  More robust than single attribution (handles input perturbations)

Implementation location:
  File: src/certify/smoothing.py
  Class: RandomizedSmoothingAttributor
  Method: certify(image, k_percent, sigma, tau, num_samples, ...)

Code example:
  import torch
  from src.models.factory import get_model
  from src.xai.attribution_unified import GradCAMUnified
  from src.certify.smoothing import RandomizedSmoothingAttributor
  
  # Setup (Eq. 1-3)
  model, _ = get_model('resnet18', num_classes=2)
  attr = GradCAMUnified(model)
  image = torch.randn(1, 3, 224, 224)
  target_class = 1
  
  # Create wrapper for attribution (implements Eq. 2-3)
  def attribution_wrapper(img, cls):
      return attr.attribute(img, target_class=cls)
  
  # Create smoother (implements Eq. 4-5)
  smoother = RandomizedSmoothingAttributor(model, attribution_wrapper)
  
  # Certify image (implements Eq. 5)
  results = smoother.certify(
      image=image,
      k_percent=30,           # Eq. 4
      target_class=target_class,
      sigma=0.15,             # Eq. 5: noise std
      tau=0.75,               # Eq. 5: certification threshold
      num_samples=100         # Eq. 5: sample count
  )
  
  # Results
  cert_map = results['certified_map']  # {-1, 0, 1}^{H×W}
  p_1 = results['p_1']  # P(important) per pixel
  p_0 = results['p_0']  # P(unimportant) per pixel
  
  # Interpretation
  important_pixels = (cert_map == 1)
  unimportant_pixels = (cert_map == 0)
  uncertain_pixels = (cert_map == -1)

Hyperparameter guidance:

  σ (sigma):
    - Definition: Standard deviation of Gaussian noise
    - Paper value: 0.15
    - Effect: Larger σ → More robust (larger R) but fewer certified
    - Range: [0.10, 0.20]
  
  τ (tau):
    - Definition: Certification threshold (must be > 0.5)
    - Paper value: 0.75
    - Effect: Larger τ → Stricter (larger R) but fewer certified
    - Range: [0.60, 0.90]
  
  K (k_percent):
    - Definition: Sparsification level
    - Paper values: [50, 30, 10]
    - Effect: Larger K → Easier to certify (more important pixels)
    - Range: [5, 100]
  
  n (num_samples):
    - Definition: Number of noisy samples
    - Paper value: 100
    - Effect: Larger n → More reliable estimates but slower
    - Range: [50, 200]

=============================================================================
EQUATION (6): RADIUS BOUND (Theory)
=============================================================================

Mathematical form:
  Theorem (Segmentation Smoothing):
    If we certify binary segmentation s(x) ∈ {0, 1}^{H×W} via
    randomized smoothing with noise std σ, then there exists
    radius R = σ·Φ^(-1)(τ) such that for any perturbation δ
    with ||δ||_2 < R, the segmentation is robustly stable.

Interpretation:
  This is the theoretical foundation for our certified radius in Eq. 7.
  The paper applies this result to our sparsified attribution h_K(x).

Reference:
  Cohen & Welling (2019) "Certified Adversarial Robustness 
  via Randomized Smoothing" - ICML

=============================================================================
EQUATION (7): CERTIFIED ROBUSTNESS RADIUS
=============================================================================

Mathematical form:
  R = σ · Φ^(-1)(τ)
  
  Where:
    σ = noise standard deviation (same as Eq. 5)
    τ = certification threshold (same as Eq. 5)
    Φ^(-1) = inverse cumulative normal distribution function
    R = robustness radius in L2 norm

Interpretation:
  For any image perturbation with L2 norm < R, the certified
  attribution map remains unchanged.
  
  Example: R = 0.10 means perturbations ||δ||_2 < 0.10 won't
  change which pixels are certified important vs unimportant.

Implementation location:
  File: src/certify/smoothing.py
  Function: scipy.special.ndtri() in certify() method
  Line: radius = sigma * ndtri(tau)

Code example:
  from scipy.special import ndtri
  import numpy as np
  
  # Paper default parameters
  sigma = 0.15
  tau = 0.75
  
  # Compute certified radius (implements Eq. 7)
  ndtri_value = ndtri(tau)  # Φ^(-1)(0.75)
  radius = sigma * ndtri_value
  
  print(f"Φ^(-1)({tau}) = {ndtri_value:.4f}")
  print(f"R = {sigma} × {ndtri_value:.4f} = {radius:.4f}")
  # Output: R = 0.1012
  
  # Interpretation: Perturbations ||δ||_2 < 0.1012 preserve certification

Computing for different parameters:
  
  σ=0.10, τ=0.75: R = 0.10 × 0.6745 = 0.0675
  σ=0.15, τ=0.75: R = 0.15 × 0.6745 = 0.1012  [Paper default]
  σ=0.20, τ=0.75: R = 0.20 × 0.6745 = 0.1349
  
  σ=0.15, τ=0.60: R = 0.15 × 0.2533 = 0.0380
  σ=0.15, τ=0.75: R = 0.15 × 0.6745 = 0.1012  [Paper default]
  σ=0.15, τ=0.90: R = 0.15 × 1.2816 = 0.1922

Relationship with other parameters:
  - Larger σ → Larger R (more robust)
  - Larger τ → Larger R (paradoxically, stricter threshold gives larger R
              because we need more samples to be consistent)
  - Trade-off: both reduce percentage of certified pixels

import torch
import numpy as np
from src.models.factory import get_model
from src.xai.attribution_unified import GradCAMUnified
from src.certify.smoothing import RandomizedSmoothingAttributor

# ===== Equation (1): Classifier =====
print("Eq. (1): Loading classifier f...")
model, config = get_model('resnet18', num_classes=2)
image = torch.randn(1, 3, 224, 224)
logits = model(image)  # [1, 2]
pred_class = logits.argmax(dim=1).item()  # 0 or 1
print(f"  Prediction: class {pred_class}")

# ===== Equations (2-3): Attribution =====
print("Eq. (2-3): Computing attribution h(f, x, y)...")
attr = GradCAMUnified(model)
heatmap = attr.attribute(image, target_class=pred_class)
print(f"  Heatmap shape: {heatmap.shape}")
print(f"  Heatmap range: [{heatmap.min():.3f}, {heatmap.max():.3f}]")

# ===== Equation (4): Sparsification =====
print("Eq. (4): Sparsifying to h_K(x)...")
def sparsify(heat, k):
    flat = heat.flatten()
    threshold = np.percentile(flat, 100 - k)
    return (heat >= threshold).astype(np.float32)

for k in [50, 30, 10]:
    mask = sparsify(heatmap, k)
    pct_ones = 100 * np.mean(mask)
    print(f"  K={k}%: {pct_ones:.1f}% are 1 (important)")

# ===== Equations (5) & (7): Certification & Radius =====
print("Eq. (5-7): Randomized smoothing certification...")

def attribution_wrapper(img, cls):
    return attr.attribute(img, target_class=cls)

smoother = RandomizedSmoothingAttributor(model, attribution_wrapper)

results = smoother.certify(
    image=image,
    k_percent=30,        # Eq. 4
    target_class=pred_class,
    sigma=0.15,          # Eq. 5-7
    tau=0.75,            # Eq. 5-7
    num_samples=100      # Eq. 5
)

# Get outputs
cert_map = results['certified_map']  # Eq. 5 output
p_1 = results['p_1']               # Eq. 5 output
p_0 = results['p_0']               # Eq. 5 output
radius = results['certified_radius']  # Eq. 7 output

print(f"\nResults:")
print(f"  Certified pixels: {results['pct_certified']:.1f}%")
print(f"    Important (1):  {results['pct_certified_1']:.1f}%")
print(f"    Unimportant (0):{results['pct_certified_0']:.1f}%")
print(f"  Abstained pixels: {results['pct_abstained']:.1f}%")
print(f"\n  Robustness guarantee (Eq. 7):")
print(f"    R = σ·Φ^(-1)(τ)")
print(f"    R = 0.15 × Φ^(-1)(0.75)")
print(f"    R = {radius:.4f}")
print(f"\n  Interpretation: Perturbations with ||δ||_2 < {radius:.4f}")
print(f"  will not change the certified attribution map.")
